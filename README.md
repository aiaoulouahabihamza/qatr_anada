# قَطْرُ النَّدَىٰ — Qatr Al Nada

منصة ويب إسلامية شاملة ومتطورة، تعمل كتطبيق ويب تقدمي متكامل (**PWA - Progressive Web App**) مع دعم كامل للتشغيل دون اتصال بالإنترنت (**Offline-First**). صُممت المنصة بواجهة عربية أصيلة تراعي النسبة الذهبية وتوفر تجربة قراءة مريحة للعين في الوضعين النهاري والليلي.

---

## 🌟 المميزات الرئيسية

### 1. المصحف الشريف والقرآن الكريم (`/quran/`)
- **قراءة متعددة الروايات**:
  - **رواية ورش عن نافع بالرسم المغربي الأصيل** (المصحف المحمدي الشريف، بتوزيع الأسطر والخط المغربي المخطوط).
  - **رواية حفص عن عاصم** بالرسم العثماني المعتمد لمجمع الملك فهد.
  - **رواية ورش عن نافع** بالرسم المشرقي المعتمد.
- **تنسيق مطابق للمصحف المطبوع**: صفحات متناسقة وموزعة بدقة تحاكي المصاحف المعتمدة مع محاذاة جمالية لفاتحة الكتاب وبداية سورة البقرة.
- **التفسير الميسر المباشر**: النقر على أي آية يتيح الوصول السريع إلى تفاسير متعددة موثوقة (التفسير الميسر، الجلالين، السعدي، ابن كثير، البغوي، القرطبي، الطبري، الوسيط) مع مطابقة رقمية دقيقة بين الروايات.
- **الاستماع والتلاوة المتزامنة**:
  - مشغّل صوتي مدمج يضم نخبة من مشاهير القرّاء لكل رواية (عبد الباسط عبد الصمد، العفاسي، المنشاوي، الحصري، الكوشي، الدوسري، الغامدي، وغيرهم).
  - **تظليل آلي وتتبع متزامن للآية الجارية** أثناء الاستماع، مع تقليب تلقائي للصفحات عند نهاية كل صفحة.
  - تخزين مؤقت ذكي للمقاطع الصوتية لتقليل استهلاك البيانات وإتاحة الاستماع دون إنترنت.
- **العلامات المرجعية الذكية**: حفظ الآيات والسور بألوان وأسماء مخصصة والرجوع إليها بلمسة واحدة.
- **حفظ الموضع التلقائي**: استئناف القراءة فوراً من آخر صفحة وآية وصل إليها القارئ.

### 2. الأذكار اليومية وحصن المسلم (`/adkar/`)
- فهرس كامل وشامل لأذكار الصباح والمساء، النوم والاستيقاظ، الصلاة، والمسجد مأخوذة من حصن المسلم.
- عدّاد رقمي تفاعلي لكل ذكر مع اهتزاز لمسي (Haptic Feedback) وشريط تقدم إنجاز الأذكار.
- حفظ تقدم الأذكار اليومي تلقائياً وإمكانية نسخ نصوص الأذكار ومشاركتها.

### 3. مواقيت الصلاة والقبلة (`/prayer/`)
- حساب دقيق لمواقيت الصلاة الخمس مع دعم مدن المملكة المغربية والعالم العربي.
- عداد تنازلي تفاعلي يُظهر الوقت المتبقي للصلاة القادمة بدقة الدقيقة والثانية.
- تقويم هجري وميلادي متزامن، مع إمكانية تعديل الفروق الزمنية بالدقائق.

### 4. الحديث النبوي الشريف (`/hadith/`)
- **متن الأربعين النووية كاملة** (42 حديثاً شريفاً) مع الضبط التام بالشكل.
- شروح تفصيلية معتمدة لكل حديث، مع إيضاح الفوائد المستنبطة، الإعراب، والتحفة الربانية.

### 5. الأدعية المأثورة (`/duaa/`)
- موسوعة منتقاة لأدعية القرآن الكريم والسنة النبوية الشريفة مقسمة حسب الأبواب والمناسبات.
- معاني الكلمات الغريبة وتخريج الأحاديث لتوثيق المصادر.

## 🌓 التصميم والمظهر (UI & Theme)

- **الوضع النهاري (Cream & Gold)**: لوحة لونية هادئة مستوحاة من رمال الصحراء والورق القرآني الكريمي (`#E8DDCB`) مع ألوان الحبر الكحلي (`#031634`) والذهب الرملي (`#CDB380`) والأخضر الزمردي (`#036564`).
- **الوضع الليلي (Dark Neutral)**: تباين مريح للعين أثناء القراءة في الظلام (`#121417` للخلفية مع نص عاجي دافئ وحواف ناعمة غير مجهدة).
- **أصالة الخط العربي**: استخدام خطوط عربية عالية الجودة (خط النسخ، خط الرقعة، خط الرسم المغربي العتيق، وخط أسماء السور المخطوط).

## ⚡ البنية التقنية (Tech Stack)

تم بناء المنصة وفق معايير برمجية صارمة تركز على الأداء الفائق والخفة وسهولة الصيانة:

- **الواجهة الأمامية (Frontend)**:
  - **HTML5 دلالي (Semantic HTML)** مع دعم كامل لاتجاه القراءة من اليمين لليسار (`dir="rtl"`).
  - **CSS3 نقي (Vanilla CSS)** يعتمد متغيرات الألوان والتصميم المرن (Custom Properties & Flex/Grid) دون الحاجة لمكتبات ضخمة.
  - **JavaScript حديث (Vanilla ES6+)** خالٍ تماماً من التبعيات الخارجية (No heavy frameworks / No React overhead)، مما يضمن سرعة تحميل شبه لحظية.
- **تطبيق ويب تقدمي (PWA)**:
  - ملف البيان `manifest.webmanifest` متوافق مع كافة معايير التثبيت على Android و iOS و Desktop.
  - خدمة العامل `sw.js` تدير ذاكرة التخزين المؤقت مع استراتيجيات متقدمة (**Cache-First** للأصول والخطوط و **Network-First with Cache Fallback** للبيانات والصفحات).
- **الاستضافة**:
  - موقع ثابت بالكامل (Static Assets) يُنشر على **Cloudflare** عبر `wrangler`، دون خادم خلفي.
  - ملف `_headers` يضبط ترويسات الأمان والتخزين المؤقت، و`404.html` صفحة الخطأ المخصصة.

## 🚀 التشغيل والتطوير المحلي

1. **تثبيت الأدوات**:
   ```bash
   npm install
   ```
2. **بدء خادم التطوير** (يطبّق `_headers` كما في الإنتاج):
   ```bash
   npm run dev
   ```
   يفتح التطبيق على الرابط الذي يعرضه `wrangler` (غالبًا `http://localhost:8787`).

3. **النشر**:
   ```bash
   npm run deploy
   ```

> **عند تعديل ملفات ثابتة (صفحات HTML أو الصور أو الخطوط):** زِد رقم `SHELL_CACHE` في `sw.js` حتى يحدّث الـ Service Worker نسخته المخزنة. ملفات JS و CSS تتحدث تلقائيًا في الخلفية.
